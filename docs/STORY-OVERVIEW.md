# 《谢水仪式》剧情总览（讨论稿）

1985 年，中爪哇特曼贡一带的虚构山村。哥哥失踪七年后，莉妮回来帮父亲领谢水队。散戏时，守夜的达尔马没回来。父亲说他先走了，莉妮却在桥头看见他的鞋。这也是洪水过后，父亲说起哥哥时用过的话。

单一主角莉妮。主线约 100 分钟，完整体验目标 90–120 分钟。对白和调查从莉妮的视角展开。

# 一　白日领路（17 分钟）

父亲萨斯特罗平时替村里分水，今年把领队的活交给莉妮。早上她去磨坊帮萨丽婶折蕉叶碗，再领着抬供品的人走过木桥，到新泉边祈祷。分供品时，有人来问父亲自家的田何时轮到水。父亲翻开分水册，指着一行「转新泉」，说旧渠那几家早搬走了。

达尔马带莉妮认过两处竹梆。旧渠敲，是叫人往高处撤。上坡岗亭回梆，才算人到齐。问起七年前，他说第一遍梆响完，看见她哥哥提灯往旧渠去了。莉妮还记得那天两个人吵过架。哥哥说攒够了车钱，要到镇上找活，她回他一句「那你走吧」。后来父亲告诉她，哥哥确实坐上了车。

# 二　散戏（18 分钟）

皮影戏散了。萨丽婶在长凳上包剩饭，问达尔马那份要留到几时。父亲让她带回家，说人早走了。莉妮去收灯，发现达尔马的拖鞋还在桥头。左脚那只用铜丝拧过，下午她帮他修的。她弯腰去捡，桥板底下传来达尔马的声音：「先别拿。」

父亲也听见了。他把鞋提起来，叫莉妮先去让萨丽婶把孩子抱回屋。等莉妮折回来，皮影的白幕上还有四个抬担的人影。后台的灯已经熄了。她绕到桥边，看见一副湿布罩着的棺材沿旧路过去。最后一块桥板沉下去，隔了好一会儿才弹回来。

# 三　回梆（25 分钟）

萨丽婶把孩子安顿好，才跟莉妮说起七年前。她家当时换了取水口，人还住在旧渠边。洪水来时，她困在磨坊二楼。儿子在下游，是莉妮的哥哥背他上坡的。哥哥把孩子交给达尔马，又提灯回去接人。

玩家从「物品栏 → 人物」翻出父亲和达尔马的原话，用两处岗亭的位置追问。父亲说「我听见回梆了」。达尔马白天却说过，那晚他守在坡上，迟迟等不到最后几个人，手里的梆槌一次都没落下。到了闸台，父亲才说，那声回梆是从他脚底下传来的。莉妮问他还看见了什么。他指着弯道，说她哥哥的灯当时还亮着。

# 四　旧渠夜袭（25 分钟）

旧渠上传来一声竹梆。莉妮从闸台望见达尔马提灯上桥，还没来得及喊他，悬首就从背后缠住他的脚，把人拖进暗处。这里接《旧渠夜袭》CG。油灯滚过桥沿，落进水里。莉妮随后被悬首追赶，实际追逐约 2–3 分钟。

她沿渠找达尔马，看见弯道前又亮了一盏灯。她跟了几步，才发现那团伏火照不亮脚下的湿木板。折回时，她躲进芭蕉丛，隔着叶子看见一只手按过来。那只手松开后，她才看清叶子后面有条下渠的便道。她在桥墩下找到达尔马。他还活着，一只脚踩不到地。两人沿来路回村。

# 五　请你再说一遍（15 分钟）

天快亮时，莉妮把达尔马带到散戏前那张桌子旁。萨丽婶找来一块干布，给他裹住脚。莉妮请父亲当着当年从磨坊出来的人，再说一次哥哥是什么时候走的。父亲承认，他扳下闸杆时，知道儿子还在旧渠。他眼看磨坊二楼的水涨到窗台，莉妮和萨丽婶都在里面。洪水过后，确实有车载人离村。他借这辆车给儿子的失踪编了个去处。

父亲念到哥哥的名字，桥底下有人答了一声「到了」。莉妮把册子推给父亲，让他把那晚的事写上去。桥那头，渠底领队在最后一块桥板上站了一会儿。哥哥从前带队，每次过桥都要停在那儿等后面的人。这一次，莉妮等到它走远才把灯收起来。

# 1978 年洪水当晚

1. 水上涨，达尔马敲旧渠的竹梆，叫人往坡上撤。他上坡接应，最后几个人没到，所以没有回梆。

2. 哥哥提灯往回走，背出萨丽婶的孩子，把他交给达尔马。他又返回旧渠。

3. 父亲在闸台看见弯道里的灯，也看见磨坊二楼的水快到窗台。他听见闸台下有一声像回梆的响动，认出了儿子的灯，还是开闸把水分进旧渠。

4. 哥哥当夜未归。救援车后来确实开出了村。父亲告诉莉妮哥哥坐上了那辆车，萨丽婶一直没有说出儿子是怎么回来的。

# 可以先改的几处

- **哥哥最后折回去找谁。** 目前只定了他救出萨丽婶的孩子。第二次回去找的人还可以补进白天的戏。

- **达尔马那晚为什么又去桥上。** 这版暂按他听见旧岗亭响，过去查看。若改成他主动去补敲七年前没敲的回梆，就需要提前写他这些年为什么一直等到今天。

- **结尾那声「到了」是谁答的。** 目前只让莉妮和父亲都听见。领队是不是哥哥，可以留在他过桥等人的动作里。

- **「先走了」的短分支。** 如果莉妮在散戏后接受父亲的说法，就读到一段达尔马也被记成「离村」的结尾。随后可以跳回散戏，用已读的证词继续查。可作为短支线。
